# imanlib

## Правила работы

При работе с библиотекой обязательно следуй инструкциям [IDLE.md](IDLE.md).

## Суть библиотеки

`imanlib` — Rust-библиотека локального IPC и общих примитивов дисплея/ввода
для `iman`, IGUI и других процессов Linux.
Она предоставляет JSON-протокол, неблокирующий транспорт через Unix-сокеты,
клиент и сервер с ограниченными размерами сообщений, очередями и таймаутами.
Сервер создаёт приватный сокет на проверенной tmpfs и проверяет учётные данные
клиентов через `SO_PEERCRED`.
Модуль `igui` содержит общие типы состояния, параметров и результатов GUI-команд;
`igui_iman_stub` — тестовую заглушку части IPC-команд iman для самостоятельного
IGUI, не менеджер сеанса.
Диагностические модули предоставляют ограниченные чтения procfs, общие показатели
дисплея и ввода.
Модули `filesystem` и `evdev` предоставляют запрос характеристик файловой системы
по удерживаемому дескриптору, метаданные устройств и чистые преобразования ввода.
Базовый модуль `input` с состоянием логических кнопок доступен без features.
Опциональные features `graphics`, `drm` и `input` добавляют пиксельную поверхность,
DRM/KMS и профили, read-only источники и модель теста контроллеров. Приобретение
устройств и опрос — только через явные вызовы приложения; фоновой работы нет.
Навигация меню, жизненный цикл процессов и политика записи на SD остаются
в приложениях. Библиотека не зависит от их исходников или ресурсов.
